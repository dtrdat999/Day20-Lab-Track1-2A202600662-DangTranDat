# Flow Map

Start → AI Capability Onboarding → Trip Input → AI Draft Itinerary → Evidence & Assumptions → Ask: Missing Transport → Recovery: Trip Too Intense → Uncertainty: Opening Hours / Price → Feedback Loop → Final Review.

Mục tiêu của flow là cho thấy người dùng hiểu AI biết gì, chưa biết gì, đang giả định gì, và có thể kiểm soát/sửa/hoàn tác ở đâu.
