# Feedback Matrix

| Loại | Ví dụ trong prototype |
|---|---|
| User → System explicit | User chọn “quá dày”, “vượt ngân sách”, “không hợp sở thích”. |
| User → System implicit | User xoá nhiều điểm, mở phần chi phí nhiều lần, undo sau khi AI tối ưu. |
| System → User explicit | Hệ thống cảnh báo dữ liệu chưa chắc, nói rõ AI không tự booking. |
| System → User implicit | Badge ACT/ASK/DON’T ACT, nhãn giả định/rủi ro/recovery, trạng thái trước/sau. |
