# Scenario List

1. Onboarding: đặt kỳ vọng đúng về AI.
2. Main flow: user nhập nhu cầu và AI tạo lịch trình.
3. Ask state: AI hỏi phương tiện vì thiếu dữ liệu quan trọng.
4. Recovery 1: user phản hồi lịch quá dày, AI điều chỉnh nhẹ hơn.
5. Recovery 2: dữ liệu giá vé/giờ mở cửa chưa chắc, AI không tự cam kết.
6. Feedback: user phản hồi rõ lý do và hệ thống ghi nhận tín hiệu hành vi.
